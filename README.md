# JC "Raynor" Code Re-Pro

### cmpRehensive: 
First personal project, a binary comprehensive-comparer. Reads directories and children byte by byte to find duplicates. Created to solve issues with redundancies in backups that may have been saved under other names.

### School:

### shushCopy: 
Sanitized and highly portable simple api for creating and arbitrarily interacting with a local vm. Created for work, personally used to exercise porting, error, and security research for fun.
